# 조두현 포트폴리오

> 기술로 비즈니스의 연속성을 확보하고, 팀의 성장을 설계하는 풀스택 개발자입니다.

11년 동안 이커머스, 항공, 금융 결제 등 높은 안정성과 가용성이 필요한 도메인에서 시스템을 설계하고 운영해왔습니다.  
레거시 시스템의 구조적 한계를 이해하고 개선하는 일에서 시작해, 최근에는 Kubernetes, ArgoCD, GitOps, AI/RAG 기반 사내 플랫폼까지 실무에 적용하며 시스템의 지속 가능성과 운영 효율을 높이는 데 집중하고 있습니다.

## 핵심 역량

- 레거시 시스템 분석 및 현대화
- Java Spring Boot, NestJS, Node.js 기반 백엔드 개발
- 이커머스 상품, 주문, 배송 도메인 시스템 설계
- Kubernetes, Docker, ArgoCD 기반 운영 환경 고도화
- RAG, LLM, AI 추천 및 이미지 처리 서비스 운영
- 대용량 데이터 처리 및 검색 색인 구조 설계
- API 표준화, 예외 처리, 외부 연동 안정화
- 팀 리딩, 코드 리뷰, 기술 공유 문화 정착
