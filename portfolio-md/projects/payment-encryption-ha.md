# 금융 보안 준수 결제 암호화 및 서버 이중화

## 개요

여전법 준수를 위한 카드 결제 데이터 암호화 서버와 결제 서버 이중화 구조를 구축했습니다.

## 도메인

금융 결제 보안

## 담당 역할

- 카드 결제 데이터 암호화 서버 구축
- 결제 서버 이중화 시스템 구축
- .NET 기반 결제 시스템 개발 및 운영
- 금융 보안 감사 대응

## 성과

- 금융 보안 감사 통과
- 고가용성 운영 환경 확보
- 결제 시스템 가동률 99.9% 달성

## 사용 기술 및 키워드

금융 보안, 결제 암호화, HA, .NET

## 문제 해결 관점

이 프로젝트에서는 단순 기능 구현보다 운영 안정성, 장애 감소, 유지보수 효율, 데이터 정합성을 함께 고려했습니다. 기존 업무 흐름을 분석하고 반복적인 수작업이나 장애 요인을 구조적으로 줄이는 방향으로 개선했습니다.
