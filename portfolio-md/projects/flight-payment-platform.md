# 항공권 제휴 API 및 결제 플랫폼 구축

## 개요

항공권 제휴 API와 결제 시스템을 구축하고 환불 자동화 프로세스를 개발했습니다.

## 도메인

항공권 예약/결제

## 담당 역할

- 대한항공 API 연동
- 아시아나 API 연동
- 스카이스캐너 API 연동
- 네이버페이/KCP 결제 시스템 구축
- 환불 자동화 개발

## 성과

- 항공권 예약/결제 프로세스 자동화
- 결제 안정성 확보
- 제휴 채널 확장
- 매출 기여

## 사용 기술 및 키워드

항공 API, 결제, 네이버페이, KCP, 환불 자동화

## 문제 해결 관점

이 프로젝트에서는 단순 기능 구현보다 운영 안정성, 장애 감소, 유지보수 효율, 데이터 정합성을 함께 고려했습니다. 기존 업무 흐름을 분석하고 반복적인 수작업이나 장애 요인을 구조적으로 줄이는 방향으로 개선했습니다.
