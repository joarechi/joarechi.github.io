# 이미지 API 서버 리뉴얼 및 인프라 마이그레이션

## 개요

VMware 서버 이전과 이미지 API 서버 리뉴얼을 통해 서버 안정성과 유지보수성을 개선했습니다.

## 도메인

이미지 API 서버

## 담당 역할

- VMware 서버 이전
- 이미지 API 서버 리뉴얼
- PHP 기반 구조를 Java 기반 구조로 전환
- 서버 운영 구조 개선

## 성과

- 인프라 현대화를 통한 서버 안정성 향상
- 유지보수 비용 절감
- 이미지 처리 속도 개선

## 사용 기술 및 키워드

PHP, Java, VMware, API 서버, 인프라 마이그레이션

## 문제 해결 관점

이 프로젝트에서는 단순 기능 구현보다 운영 안정성, 장애 감소, 유지보수 효율, 데이터 정합성을 함께 고려했습니다. 기존 업무 흐름을 분석하고 반복적인 수작업이나 장애 요인을 구조적으로 줄이는 방향으로 개선했습니다.
