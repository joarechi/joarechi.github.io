# 상품/배송 관리 시스템 개발 및 고도화

## 개요

상품관리 SaaS의 안정화와 배송관리 API 개발, 주문관리 DB 및 검색 색인 구조 설계를 수행했습니다.

## 도메인

상품/배송 SaaS

## 담당 역할

- 상품관리 QA 및 기능 고도화
- 주문관리 DB 설계
- 검색엔진 색인 구조 설계
- 배송관리 API 개발

## 성과

- 상품관리 SaaS 런칭 완료
- 고객 피드백 기반 시스템 안정화
- 주문 검색 성능 최적화
- 배송 데이터 처리 안정성 향상

## 사용 기술 및 키워드

SaaS, 상품관리, 배송 API, DB 설계, 검색 색인

## 문제 해결 관점

이 프로젝트에서는 단순 기능 구현보다 운영 안정성, 장애 감소, 유지보수 효율, 데이터 정합성을 함께 고려했습니다. 기존 업무 흐름을 분석하고 반복적인 수작업이나 장애 요인을 구조적으로 줄이는 방향으로 개선했습니다.
