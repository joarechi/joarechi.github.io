# WinForm 솔루션 운영 및 백엔드 현대화

## 개요

C# WinForm 기반 마켓 관리 솔루션과 Windows Service 기반 백엔드를 Java Spring Boot API로 전환했습니다.

## 도메인

레거시 현대화

## 담당 역할

- C# WinForm 클라이언트 유지보수
- Windows Service 기반 백엔드 분석
- Java Spring Boot API 서버 전환
- WinForm과 신규 API 서버 간 인터페이스 설계
- 통신 구조 개선

## 성과

- 서버 응답 시간 평균 300ms 단축
- 시스템 가용성 향상
- OS 종속적 구조를 현대적 API 아키텍처로 개선
- 운영 리소스 월 80시간 절감

## 사용 기술 및 키워드

C#, WinForm, Java, Spring Boot, API Modernization

## 문제 해결 관점

이 프로젝트에서는 단순 기능 구현보다 운영 안정성, 장애 감소, 유지보수 효율, 데이터 정합성을 함께 고려했습니다. 기존 업무 흐름을 분석하고 반복적인 수작업이나 장애 요인을 구조적으로 줄이는 방향으로 개선했습니다.
