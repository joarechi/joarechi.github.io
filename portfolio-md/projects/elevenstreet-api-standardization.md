# 11번가 API 및 배송정보 API 표준화 고도화

## 개요

11번가 주문/배송 API 연동 구조를 개선하고 대량 주문 동기화 로직과 예외 처리 표준화를 수행했습니다.

## 도메인

외부 마켓 API 연동

## 담당 역할

- 11번가 주문/배송 API 연동 구조 개선
- API 응답 및 예외 처리 표준화
- 대량 주문 동기화 로직 고도화

## 성과

- 외부 API 연동 안정성 향상
- 운영 장애 감소
- 유지보수 효율성 개선
- 데이터 정합성 개선

## 사용 기술 및 키워드

11번가 API, 주문 동기화, 배송 API, 예외 처리

## 문제 해결 관점

이 프로젝트에서는 단순 기능 구현보다 운영 안정성, 장애 감소, 유지보수 효율, 데이터 정합성을 함께 고려했습니다. 기존 업무 흐름을 분석하고 반복적인 수작업이나 장애 요인을 구조적으로 줄이는 방향으로 개선했습니다.
