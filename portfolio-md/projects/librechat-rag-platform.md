# 사내 통합 AI 플랫폼 LibreChat RAG 기능 추가

## 개요

사내 문서를 벡터 데이터베이스와 연동하여 내부 지식 답변 기능을 추가했습니다.

## 도메인

사내 AI 플랫폼

## 담당 역할

- LibreChat 프로젝트 운영
- 사내 문서 기반 RAG 아키텍처 설계
- 벡터 데이터베이스 연동
- RagChain 기반 내부 지식 답변 기능 추가

## 성과

- 인사 운영 업무의 반복 질의 프로세스 개선 시도
- RAG 시스템 설계, 벡터화, 답변 정교화 경험 확보
- AI 서비스를 업무 워크플로우에 안착시키기 위한 기획적 관점 확보

## 사용 기술 및 키워드

LibreChat, RAG, LLM, Vector DB, RagChain

## 문제 해결 관점

이 프로젝트에서는 단순 기능 구현보다 운영 안정성, 장애 감소, 유지보수 효율, 데이터 정합성을 함께 고려했습니다. 기존 업무 흐름을 분석하고 반복적인 수작업이나 장애 요인을 구조적으로 줄이는 방향으로 개선했습니다.
